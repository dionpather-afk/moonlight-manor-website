# Moonlight Manor Website

A proposal website for Moonlight Manor Boutique Guesthouse in Victoria West, Northern Cape, South Africa.

## Technology

- Astro
- Responsive HTML and CSS
- Static-site output
- GitHub Actions build check

## Run locally

```bash
npm install
npm run dev
```

Create a production build:

```bash
npm run build
npm run preview
```

## Pages

- Home
- Our Story
- Accommodation
- Experiences
- Gallery
- Contact & Booking
- Privacy Policy

## Design direction

- Charcoal: `#282722`
- Heritage ivory: `#F2EBDD`
- Antique bronze: `#A47C4D`
- Stone: `#77715F`
- Editorial serif headings with a clean sans-serif body font

## Content and launch checks

This is a proposal preview, not an approved live website. Public listing information has been used only as a starting point. The following must be confirmed by the property owner before launch:

- Final room names, room count, occupancy and amenities
- Direct telephone number, email address and booking process
- Current meal options, prices, check-in/out times and house rules
- Permission to use property photographs and final approved image selection
- Final privacy policy and any analytics or enquiry-form data handling

Do not publish unverified prices or policies. The map is centred on the published property address: 11 Brinkman Street, Victoria West, 7070, Northern Cape, South Africa.

## Photography

The `public/images/` folder is reserved for owner-approved photographs of the actual property. Until those images are added, the image areas use neutral fallbacks. Do not substitute generic stock photography as if it depicts Moonlight Manor.

## Deployment

The site is configured for static output. A hosting target and preview deployment still need to be connected and tested. No production deployment is configured here.
